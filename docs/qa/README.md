# QA screenshots

Generated by `node scripts/shoot.mjs`. The images themselves are git-ignored —
they are a working artefact of a review, not part of the project.

```bash
node scripts/shoot.mjs --url http://localhost:3130/ --name home --width 1440 --sweep 800
node scripts/shoot.mjs --url http://localhost:3130/ --name connects --width 1440 --scroll 4200,5000,5800
```

The script drives the installed Chrome over the DevTools Protocol with Node 22
 built-ins, so it can scroll before each capture. Nothing is installed.
